2. Who We Are

LOVE CARE GLOBAL HOME NURSING — Provides home nursing booking platform connecting Clients (patients families) with Nurses (licensed professionals) across Ghana + 7 other countries. We are platform, not direct medical provider — Nurses are independent contractors verified by CEO.

3. Client Accounts — Photo Name Phone Email + Time Saved

When you sign up as client, we save: Client Photo URL, Full Name, Phone with country code (+233), Email, LatLng (location), ID, Time (createdAtStr en-GH) in localStorage + Firebase clients/{phone} + bookings/{id}. You must provide accurate info. Edit in client-settings.html — Link: "Edit name & picture" in client-dashboard.html. Verified badge shown after email verification.

4. Booking a Nurse — How It Works

  1. Client goes to book-nurse.html → Fills: Patient Name, Phone, Location (with GPS LatLng), Service Type, Date/Time (real date), Amount (GHS), Notes.
  2. Client pays via Paystack (MoMo Ghana / Card outside Ghana) → Booking ID generated (LCG-...).
  3. Booking saved to Firebase: bookings/{id} with: Client Photo Name Phone Email + Patient Name Phone Location LatLng + Service + Amount + Paystack Ref + Status pending + Time.
  4. Nurse sees job in my-job-offer.html → Can Accept ✅ or Reject ❌ with reason + Auto Navigation to Patient Location (Google Maps dir/?api=1&destination=patientLatLng).
  5. If Accepted: Client sees alert in client-alerts.html with Nurse Big Card: Photo + Name + Phone + Email + Specialty + Rating + Buttons: Call Nurse, WhatsApp Nurse, Auto Navigation to Patient, Live Tracking.
  6. If Rejected: Client sees Rejected card + Options: Book Another Nurse (book-nurse.html) or Increase Payment Rate (book-nurse.html?increaseRate=1).

5. Nurse Accounts & Duties

Nurses must be licensed, provide photo, name, phone, email, specialty, rating, available days. When accepting job, nurse must go to patient location using auto-navigation, start service on time, be professional. Nurse photo + phone shown to client after acceptance for contact. No-show = client can complain in client-complaint.html + request refund in refund-query.html + CEO action.

6. Payments — Paystack Only

All payments via Paystack. Ghana: MoMo (MTN, Vodafone, AirtelTigo). Outside Ghana: Card. Amount paid now saved in booking. Paystack ref saved for refund verification. Transaction fees 1.9% may not be refundable. CEO dashboard tracks all payments in bookings + allBookings + paystack refs.

7. Refunds — How Client Can Refund Their Payment

Full details in refund.html and form in refund-query.html. Summary:
- 100% Before Accept: Cancel before nurse accepts in my-job-offer.html → 100% refund.
- 100% Nurse Rejected / No-Show / Double Payment: Nurse rejects or no-show → 100% refund OR increase rate and rebook.
- 50% Within 24h After Accept, Service Not Started: Cancel within 24h after acceptance → 50%.
- 0% After Service Starts: No refund once nurse arrives and starts care (verified by GPS navigation), unless no-show.
How to Request: client-dashboard.html → My Bookings (my-bookings.html — real date) → Refund Query (refund-query.html) → Select booking → Fill reason, amount, MoMo number, details → Submit. Saves Client Photo Name Phone Email + Patient + Nurse + Time → Shows in ceo-refund-management.html for CEO to Approve / Mark Paid via Paystack within 3-5 business days. Track in refund-query.html history + client-alerts.html.

8. Complaints — Client Can Complain on Booked Nurse Only

Full flow: Client must have booked nurse (bookingId required). Go to client-complaint.html (from client-dashboard.html or my-bookings.html?complain). Fill: Complaint Type (late_arrival, unprofessional, poor_service, not_completed, rude, hygiene, theft, no_show, overcharge, other) + Detailed Text (20+ chars) + Optional: Record Audio Complaint, Record Video Evidence, Upload Photos/Videos/Documents (max 20MB each, up to 10 files). On Submit, saves to Firebase: clientComplaints/{id}, allComplaints/{id}, ceoComplaints/{id}, complaintsByBooking/{bookingId}/{id}, complaints/{id} with: Client Photo Name Phone Email LatLng Time + Patient Name Phone Location LatLng + Nurse Name Phone Photo ID + Booking ID Service Amount Paystack Ref + Complaint Type Text Audio Video Files Status pending + Time en-GH. CEO sees LIVE in ceo-complainant.html → Can call client, call nurse, resolve. False complaints = account action.
