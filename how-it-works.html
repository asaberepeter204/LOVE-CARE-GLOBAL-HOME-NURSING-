📋 How It Works — LOVE CARE GLOBAL HOME NURSING

Simple 4-step system: Client books → ONLINE Nurse selected → Nurse accepts → Nurse navigates to PATIENT (not just client) → Care starts. Works for family bookings across cities (Accra client booking for mother in Kumasi).

🟢 ONLY ONLINE Nurses Show💰 Full & 50% Payment🎵 Custom Tone + SMS Alerts🧭 Navigate to PATIENT

👩‍⚕️ FOR NURSES — How to Appear & Get Bookings

Step 1: Register & Save Your Details — Name Photo Email Phone + Time

Go to nurse-register.html → nurse-login.html → nurses-dashboard.html

  • Enter: Full Name, Phone (+233...), Email, Photo URL, Specialty (Elderly Care, ICU, etc.)
  • Tap 💾 Save Name Photo Email Phone + Time — Saves to Firestore nurses/{uid} + Realtime nurses/{uid} + nursesByPhone + localStorage with time (e.g. Oct 28, 2026 10:30 AM GMT) + your current lat/lng
  • Your photo shows as avatar with green dot when online

Step 2: Go ONLINE — This Makes You Visible in book-nurse.html

CRITICAL — Only ONLINE nurses show for clients! Offline nurses are hidden and won't pop up.

  • In nurses-dashboard.html, you see toggle: 🟢 Go Online / Offline — Controls Client View
  • Tap 🟢 Go ONLINE Now — Appear for Clients
  • What happens behind:
    • Writes nurses/{uid}: isOnline:true, online:true, status:'online', lastSeen:Date.now(), lastActive, lat, lng, fullName, photoURL, email, phone, specialty
    • Writes onlineNurses/{uid}: {isOnline:true, lastSeen, fullName, phone, email, photoURL, lat, lng} — book-nurse.html checks this list!
    • Writes nursePresence/{uid}: {status:'online', isOnline:true, lastSeen}
    • Writes nurseLocations/{uid}: {lat, lng, lastUpdate, nurseId, nurseName, isLive:true} — For blinking green marker on client map
    • Updates every 2 minutes automatically to stay ONLINE (within 10-min threshold)
  • Badge changes to 🟢 ONLINE — Visible to clients + green dot pulsing. Status display: "You now appear in book-nurse.html and book-nurse-50-percent.html!"
  • If you close tab, you stay online for 10 mins (threshold logic). To hide instantly, tap 🔴 Go OFFLINE — Hide — Removes from onlineNurses, nurseLocations, sets status offline — Clients cannot see you.

Step 3: Set Custom Tone + SMS — Rings When Client Books You

  • Go to my-job-offer.html or nurse-settings.html — Top card: 🎵 NURSE Custom Tone — Select Song From Phone
  • Presets: New Booking Beep, Urgent Alarm (loud), Cash Cha-Ching, Gentle Bell, Afrobeat Ghana Vibe — Tap ▶️ to preview
  • Or Upload Your Own Song From Phone (MP3, M4A, WAV) — File input → Converts to base64 → Saved locally (nurse_tone_base64) + time
  • Checkbox: 💬 Also send SMS to me (works even if phone silent/data off) — FAST! — Checked = You get SMS: "🔔 NEW BOOKING! Client ASABERE PETER booked you! GHS 150..." + tone rings!
  • Tap 💾 Save Nurse Tone + SMS — Saves name, type, base64, time, smsEnabled
  • Test: 🧪 Test Ring + SMS Now — Tone rings + SMS sent to your phone
  • Enable Notifications: Tap 🔔 Enable Notifications + Vibration — Allows notification + vibration when booked

Step 4: Receive Booking — Tone + Vibration + Notification + SMS

  • Client books you in book-nurse.html (Full Pay) or book-nurse-50-percent.html (Pay 50% now)
  • Your my-job-offer.html detects NEW booking ID (prevIds check) → Rings custom tone + Vibrates [300,100,300,100,500] + Notification "🔔 NEW BOOKING! Client Booked You!" + SMS via Hubtel — 4 alerts at once!
  • SMS saved in smsLogs with photo name phone email + time for CEO audit
  • You see: Client card (who pays) + Patient card (who needs care) — Patient may be different city!
  • Cards show: Client Name Phone Email Photo, Patient Name Phone Address Lat/Lng, Total Amount GHS, Payment method

Step 5: Accept & Navigate to PATIENT — Not Just Client

  • Tap ✅ Accept + Navigate → Updates status to ACCEPTED in myJobOffers/{yourId}/{bookingId}, bookings/{bookingId}, ceoBookings
  • Starts GPS Live Tracking: watchPosition highAccuracy → Shares to nurseLocations/{id}, liveNurseLocations/{bookingId}, ceoBookings nurseLat/nurseLng, lastUpdate every few seconds
  • Bottom bar appears: 🛰️ GPS LIVE — lat,lng — Getting location... with Stop GPS button
  • Auto opens Google Maps navigation: https://www.google.com/maps/dir/?api=1&origin=yourLat,yourLng&destination=patientLat,patientLng&travelmode=driving — Nurse navigates to PATIENT house (critical for family bookings!)
  • If patient phone available, tap 📞 Call Patient or 📞 Call Client (who pays)
  • Buttons: 🧭 Navigate to PATIENT, 🗺️ View Map, 💬 WhatsApp, 📞 Call
  • Status updates: ACCEPTED → ENROUTE → ARRIVED → INSERVICE → COMPLETED via updateNurseStatus()
  • Client in client-alerts.html sees you accepted with your photo phone — His custom tone rings + SMS!

👤 FOR CLIENTS — How to Book ONLINE Nurse

Step 1: Client Auto-Login — Name Photo Email Phone + Location Captured

  • Login via Google or email → Saves to localStorage clientName, clientEmail, clientPhone, clientPhotoUrl, clientUid
  • Open book-nurse.html → Top shows CLIENT — Who pays (Auto-filled) card with your photo, name, phone, email
  • Browser asks for location permission → If allowed, captures client lat/lng → Shows ✅ Client: lat,lng + fills clientLatInput, clientLngInput, clientLocationDisplay badge
  • If denied, drag map to set location manually — Map center = client location

Step 2: See ONLY ONLINE Nurses — Offline Hidden

  • Map shows Leaflet OSM tiles + Blinking green markers for ONLINE nurses only — Each marker has pulse animation + dot
  • Top: 🟢 ONLINE NURSES ONLY — Select Nurse — Drag Map to PATIENT House
  • Buttons: 📍 My Location, 🔍 Search ONLINE Only, Radius Select (5/10/20/50 km), Badge: 🟢 X ONLINE nurses within 10km — Only online show
  • Search logic (searchNearbyNurses):
    • Fetches nurses + onlineNurses + nursePresence + nurseLocations in parallel
    • Builds onlineIds Set from onlineNurses and nursePresence where status=online
    • For each nurse, checks isNurseOnline(v): isOnline true OR online true OR status online OR lastSeen/lastActive within 10 mins OR in onlineIds OR has recent nurseLocations lastUpdate
    • If OFFLINE → Skip — Don't show! — Hidden, won't pop up for selection
    • If ONLINE + within radius (Haversine distance) → Push to list with distance, isOnline:true, lastSeen, specialty
    • Clears old markers, adds blinking markers for online nurses only
    • If none: Shows 😴 "No ONLINE nurses within X km — All offline — Nurses must go online in nurse-dashboard.html"
  • Each card shows: Photo with green dot (online indicator), Name, ⭐ Rating, 📍 distance km, 🟢 ONLINE badge, Last seen time, Specialty, Can be booked now — Custom tone + SMS will ring for nurse
  • Tap card → Preview modal: Photo, Bio, Rating, distance, Last seen, 🟢 ONLINE — Can be booked, Buttons: Close, ✅ Continue — ONLINE Nurse
  • Select → Shows ✅ Selected: 🟢 Nurse Name — ONLINE — Patient lat,lng — Nurse is ONLINE and will get tone + SMS!
  • Real-time: Refreshes every 15 seconds + Listens to nursePresence, onlineNurses, nurseLocations onValue → If nurse goes online/offline, list updates instantly!

Step 3: Enter Patient Details — Can Be Different Place!

  • CLIENT DETAILS (Payer): Auto-filled from login — Name, Phone, Email, PhotoUrl, lat/lng hidden inputs, location badge
  • PATIENT DETAILS (Who needs care):
    • Patient Name (e.g. My Mother, Father), Patient Phone, Patient Address / Location Description (e.g. House No 12, Kumasi near Kejetia), Relationship (Mother, Father, Child, Self, etc.)
    • Checkbox: Patient at same place as me? — Checked = Patient lat/lng auto-copied from client — Display: "🏥 Patient: Same as client — Nurse navigates here"
    • Uncheck if different city: "🏥 Patient: DIFFERENT — Drag map to patient house + Click Set Patient Location"
    • Button: 📍 Set Patient Location = Map Center — Gets map center lat/lng → Sets patientLatInput, patientLngInput, unchecks sameAsClient, updates display "✅ Patient SET: lat,lng — Nurse NAVIGATES HERE!" + fills patientLocationText with lat,lng if empty
    • This is critical: Client in Accra can book for mother in Kumasi — Nurse goes to PATIENT location, not client!

Step 4: Calculate — Full or 50% Payment — Paystack

  • Booking Details: Start Time (08:00), End Time (17:00), Hours/Day Auto (9.0 hrs), Care Mode Daily/Weekly (×7)/Monthly (×30), Quantity, Country Currency GHS (GHS 17/hr) or USD (USD 8/hr) LIVE from config/rates, ceoPricing, pricing — Transport GHS 100
  • calcTotal(): Hours = end - start (handles overnight), TotalHours = hrs × qty × modeMult, Base = rate × totalHours, Total = base + transport
  • Full Pay (book-nurse.html): Pay FULL Now — GHS 253 — Creates booking with status pending_full_payment, amount total, amountSplit nurse 80% CEO 20%
  • 50% Pay (book-nurse-50-percent.html): Total GHS 253 → Pay Now (50%) GHS 126.50, Pay Later (50%) GHS 126.50 — Paystack charges only 50% now (payKobo = payNow×100), status pending_50_percent, amount total, amountPaidNow payNow, amountBalance payNow
  • Calculation box shows: Start→End formatted both 12h/24h, Hours per day, Quantity×Mode, Total Hours, CEO Rate LIVE, Base, Transport, TOTAL, PAY NOW, PAY LATER

Step 5: Pay with Paystack — Booking Saved Everywhere

  • Validations: Select ONLINE nurse first (checks if selected nurse still isOnline in allNurses — If offline, alert "Selected nurse went offline — Select another"), Complete client details, Patient name phone address, Patient lat/lng set
  • If valid: Generates bookingId LCG-FULL-YYYYMMDD-RANDOM or LCG-50-YYYYMMDD-RANDOM, payKobo = total×100 or payNow×100
  • PaystackPop.setup({key: pk_live_f17ae..., email, amount: payKobo, currency: GHS/USD, ref: bookingId+Date.now(), callback, onClose}) → handler.openIframe()
  • On callback success: Creates data object with EVERYTHING: id, bookingId, clientName, clientFullName, phone, clientPhone, clientEmail, email, clientPhotoUrl, clientPhoto, photoUrl, clientUid, clientId, clientLat, clientLng, clientLatLng, clientLatitude, clientLongitude, patientName, patientFullName, patientPhone, patientPhoneNumber, patientContact, patientLocation, patientAddress, patientLocationText, patientLat, patientLng, patientLatLng, patientLatitude, patientLongitude, patientRelationship, patientLocationCapturedAt, patientLocationSource, serviceLocation {lat:pLat,lng:pLng}, destination {lat:pLat,lng:pLng}, mainLat, mainLng, destLat, destLng, lat, lng, nurseId, nurseName, nursePhone, nurseWasOnline:true, nurseOnlineAt, amount, amountPaidNow, amountBalance, payNow, payLater, currency, paymentMethod, paymentType, paystackRef, status, time, createdAt, totalHours, hrsPerDay, startTime, endTime, careMode, quantity, transport, hourlyRateUsed, service, amountSplit
  • Saves to: bookings/{bookingId}, myJobOffers/{nurseId}/{bookingId}, ceoBookings/{bookingId}, allBookings/{bookingId}, bookingsByFull or By50Percent, bookingsByFullPayment or By50Percent, clientBookings/{uid}/{bookingId}, bookingsByFull
  • Shows success modal: ✅ Full Booking Successful! ID, Nurse, Client, Patient, Amount, Location, Calculation breakdown — Buttons: Home, 👑 CEO Receiver (ceo-booking-receiver.html)
  • Double-check: Before payment, checks selected nurse still ONLINE — If offline, refresh list

  • Shows notification if permission granted

🛠️ Firebase Rules Updates Needed

Current rules miss new nodes for ONLINE filter + SMS + Tone. Add:

  • onlineNurses: .read/.write true, indexOn isOnline, lastSeen, nurseId — Stores which nurses are ONLINE for book-nurse.html to filter
  • nursePresence: .read/.write true, indexOn status, isOnline, lastSeen — Real-time online/offline presence
  • nurseLocations: Already exists but add indexOn nurseId, lastUpdate, isLive — For blinking markers + distance calculation
  • liveNurseLocations: .read/.write true, indexOn nurseId, bookingId, lastUpdate — Live GPS during job
  • smsLogs: .read/.write true, indexOn to, time, status, bookingId — Saves SMS with Photo Name Phone Email + Time
  • nurses: Add indexOn isOnline, online, isAvailable, lastSeen, lastActive, lastOnline — For isNurseOnline() filtering
  • nursesByPhone, nurseTones, clientTones: .read/.write true

Without these, clients see "Permission denied" and ONLINE filter fails. Publish updated rules in Firebase Console → Realtime Database → Rules.

💡 Tips & Best Practices

  • Nurses: Always go ONLINE before expecting bookings — Keep app open or allow background location — Updates every 2 mins to stay online — If you go offline, you disappear from client view — Set custom Afrobeat tone + SMS ON to never miss booking — Works even if phone silent!
  • Clients: Allow location permission for accurate nearby ONLINE nurses — Drag map to PATIENT exact house for accurate navigation — Use "Set Patient Location = Map Center" for family in different city — Select radius 50km if no ONLINE nurses in 5km — Check onlineCountBadge — If 0 online, try later or increase radius — Choose Full Pay for faster acceptance or 50% to pay half now
  • Family Booking Example: You in Accra (client lat/lng 5.60,-0.18) booking for mother in Kumasi (patient lat/lng 6.69,-1.62) — Set patient location to Kumasi via map drag → Nurse in Kumasi who is ONLINE will see booking → Navigates to Kumasi house → You pay, mother receives care
  • Custom Tone: Use <3MB MP3 for best localStorage quota — Preview before save — Test Ring + SMS button to confirm — Enable Notifications for extra alert
  • SMS: Requires Hubtel Ghana account + Cloud Function sendSMS — Set SMS_CONFIG.cloudFunctionUrl to your function URL — Sender ID LOVECARE must be registered with Hubtel — SMS works even if data off, critical for Ghana
  • CEO: Monitor ceo-booking-receiver.html for all bookings with client photo name phone email + time + patient location + nurse online status — Check smsLogs for SMS proof — Check nurseLocations for live tracking
