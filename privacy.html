How It Works - 7 Simple Steps

How It Works

Book a verified nurse in 5 minutes. From search to care at your doorstep.

For Clients (Patients & Families)

No app needed - works on phone browser at peter204.github.io

1
Search Nearby Nurses on Map

Go to Book Nurse page. Click Use My Location. Map shows nurses within 2km, 5km, 10km, 20km, or All Ghana. Each nurse card shows photo, qualification, experience, status (online), distance.

2
Select Nurse & Enter Details

Tap a nurse card to select. Fill: Your Name (auto from login), Phone with country code (+233 for Ghana, +234 Nigeria, +1 USA, etc.) - this phone is sent to nurse, Patient Name, Age, Service Type (general, elderly, post-surgery, baby care, 24h live-in), Country, Start Time & End Time (e.g., 08:00 to 17:00 = 9 hrs/day), Quantity (how many days/weeks/months), Transport cost.

3
Automatic Price Calculation

System calculates: Hourly Rate x Hours Per Day x Quantity + Transport. Example: 50 GHS/hour x 9 hrs/day (08:00-17:00) x 3 days = 1350 GHS + transport. Hourly rate set by CEO at ceo-dashboard.html → Pricing. You see minimum, you can offer above minimum to attract nurse faster. GHS for Ghana, USD for outside.

4
Pay Securely with Paystack

Click Book Selected Nurse → Paystack popup → Pay with Mobile Money, Card, Bank. Currencies: GHS, NGN, ZAR, USD, GBP. On success, system generates unique Booking ID like LCG-20261009-AB12CD. You see success modal with Booking ID and nurse info. Booking ID is your proof of payment.

5
Nurse Receives Job Offer Instantly

Booking saved to 5 places in Firebase Realtime Database (to fix permission_denied, rules now allow auth != null):
- bookings/{id}
- nurseBookings/{nurseId}/{id}
- myJobOffers/{nurseId}/{id} ← nurse sees this
- jobOffers/{id}
- clientBookings/{phone}/{id}
Nurse logs into nurses-dashboard.html → My Job Offers (my-job-offer.html) → Sees your job with Booking ID, your phone with country code, patient details, amount, address, GPS. Nurse can Call Client, Copy ID, Accept Job, View Details.

6
Nurse Accepts & Care Begins

Nurse clicks Accept Job → Status changes to accepted (local + Firebase). Nurse contacts you via phone. You both confirm Start Date/Time. Nurse arrives, provides care as per service booked. For live-in, provide accommodation. Use Consent Form (consent-form.html) before care.

7
Completion, Rating & Support

After service, rate nurse (ratings collection). For issues: Contact page, SOS page (sos.html) for emergencies - CEO notified via sosAlerts. CEO monitors nurses_group_chat (clean chat, no spam, master delete & block manager at CEO Dashboard only). Refund as per refund.html policy.

For Nurses

  1. Register at nurse registration page → Upload Photo, National ID, Licence, Certificate, CV, Intro Video, GPS, Phone, Email, Qualification, Experience
  2. Data goes to pendingNurses (RTDB) + nurses (Firestore) → Status pending
  3. CEO (lovecareglobal@gmail.com) reviews at ceo-dashboard.html → PAGE 1 Pending Registrations → View All Particulars → Approve/Reject
  4. Once approved, you can login at nurse-login.html (no CEO button) → Auto-login to nurses-dashboard.html, my-job-offer.html, nurse-group-chat.html (no second login)
  5. Receive job offers in My Job Offers → Accept → Contact client → Provide care → Get paid via payoutRequests → CEO approves payout at CEO Dashboard
  6. Chat with other nurses & CEO in Nurses Group Chat (nurse-group-chat.html) - clean chat, no inscriptions, CEO can block misbehaving nurses at CEO Dashboard

For CEO (lovecareglobal@gmail.com)

  • Login at ceo-login-FIXED.html (fixed toLowerCase bug, fixed Chinese mojibake, anonymous auth enabled)
  • CEO Dashboard has 4 pages: Pending, Approved, Bookings/Payouts, Pricing/Map/Group Chat Master Controls
  • PAGE 1: Pending registrations straight from Firebase - Approve/Reject - nurses can't login until approved
  • Group Chat Master Controls (moved from chat to CEO Dashboard as you requested): Master Delete (type WIPE) + Block/Unblock Manager showing ALL registered nurses from Firestore + RTDB, search, block reason
  • Pricing: Set GHS hourly and USD hourly - clients see daily = hourly x 8, weekly x 40, monthly x 160, 24h daily x 24 etc.
  • Firebase Rules: Both Realtime Database and Firestore must allow auth != null + Anonymous enabled - files provided: firebase-rules-COMPLETE-ALL-OLD-PLUS-NEW.json and firestore.rules
