How Staff Password System Works (CEO Creates Password For Each):
1. CEO opens this page (ceo-staff-manager.html) → Fills Staff Name, Email, Password, Role → Clicks Create Staff Account
2. Firebase saves to staffAccounts/{sanitized_email} = {name, email, password, role, active, createdAt, createdBy CEO, lastLogin}
3. Staff opens staff-page.html → Enters Email + Password created by CEO → System checks staffAccounts/{email} password matches → If yes, shows dashboard
4. CEO can change each person's password anytime: Click Edit in staff list → Change password → Save → Old password stops working instantly, staff must use new password
5. CEO can disable staff: Set Active = Disabled → Staff cannot login
6. All login attempts logged to staffLoginLogs for audit
7. Staff page includes all CEO features EXCEPT group chat master controls block (exempted) — Only CEO can access group chat controls in ceo-dashboard.html
8. Passwords stored plain in Firebase for CEO ease (in production hash with bcrypt) — Firebase path: staffAccounts
